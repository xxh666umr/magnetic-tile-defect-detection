==================================================
        磁瓦缺陷检测系统 —— 使用说明
==================================================

一、需要什么环境
----------------------------------------------
1. Python 3.12（本项目使用老师提供的 WinPython 便携环境：
   VisionAI_Lab\WPy64-312101）
2. 依赖库（老师环境已全部装好，无需额外安装）：
   - ultralytics 8.4.137 （YOLO 目标检测框架）
   - torch 2.13.0（CPU 版深度学习框架）
   - opencv-python 4.14.0（图像处理）
   - pillow、numpy（图像与数组）
3. 无需 GPU，CPU 即可运行。

二、怎样启动
----------------------------------------------
方式一（命令行，推荐）：
  打开 WinPython 的"WinPython Command Prompt"，执行：
    python main.py

方式二（IDLE）：
  双击 WPy64-312101 下的 "IDLE (Python GUI).exe"，
  打开 main.py，按 F5 运行。

三、怎样操作
----------------------------------------------
1. 打开单张图片：点击【打开单张图片】，选择一张磁瓦图（jpg/png）。
2. 单张检测：点击【开始检测】，界面显示缺陷框、类别、置信度，
   右侧显示判定结果（OK / NG）和检出的缺陷明细。
3. 批量检测：点击【选择文件夹批量检测】，选择图片文件夹，
   系统逐张处理，实时显示进度条和每张结果；点击列表条目可查看该图详情。
4. 保存结果：检测后点击【保存当前结果】，带框图片存入 results 目录，
   记录写入 history.json（可随时在【查看历史记录】中回看，关闭再打开仍保留）。
5. 异常提示：遇到图片打不开、未选图、模型找不到等情况，程序会弹窗
   明确提示，且不会把失败显示成 OK。

判定规则：
  有符合置信度阈值（0.25）的缺陷框 => 判定 NG；
  没有缺陷框 => 判定 OK（并在结果中注明"没检出不代表一定没有缺陷"）。

四、结果存在哪里
----------------------------------------------
  工程目录：VisionAI_Lab\MT_defect_system\
    - main.py            系统主程序
    - best.pt（在 runs\magnetic_tile_defect\weights\）  训练好的模型
    - history.json       检测历史记录（JSON）
    - results\           保存的带框结果图片
    - examples\          课堂展示用示例图片

五、几次主要修改记录与 AI 帮助说明
----------------------------------------------
1. 最初计划用 GPU 版 PyTorch 训练，后发现老师环境为 CPU 版，
   改用老师自带环境训练，保证课程环境一致、可复现。
2. 训练产物目录原计划用中文路径，发现 ultralytics 对中文路径
   处理异常，改为纯英文路径 MT_defect_system，规避兼容问题。
3. AI 用于：代码初稿、路径与报错排查、数据集与类别确认、
   评价脚本编写；本人负责运行、修改和逐项测试。
